# Із — дневник атмосферы дня

Прототип для Genesis Hackathon (кейс ArtTech «Make the Invisible Visible»).
«Із» по-казахски означает «след». Человек пишет, как прошёл день, прикладывает фото и песню, а дневник собирает из этого живую вертикальную страницу 9:16. На странице движение идёт под песню, а палитра, фактура, ритм, типографика и голос озвучки выбираются по настроению дня. Каждый день хранится в отдельной папке с названием, которое система придумывает по записи. Все дни вместе образуют ленту одного дневника.

## Запуск

Сборка не нужна. Это статический сайт: `index.html` и пять скриптов в `js/`.

```bash
python3 -m http.server 8000      # затем открыть http://localhost:8000
```

Сайт можно положить на GitHub Pages, Netlify или любой статический хостинг. При первом открытии создаются 6 демо-дней: процедурные «фото» и генеративные треки проходят через тот же конвейер анализа, что и записи пользователя.

Нужен современный Chrome, Edge или Firefox. Видео записывается через MediaRecorder (Chrome/Edge), озвучка работает через Web Speech API.

## Как это устроено

| Файл | Что делает |
|---|---|
| `js/analyze.js` | Анализ ввода. **Текст:** русский лексикон (≈300 основ) даёт валентность, энергию, сезон, время суток, место, людей, погоду, ощущения и ключевую фразу. **Фото:** k-means на 5 цветов, яркость, насыщенность, тепло, контраст. **Музыка:** свой FFT считает темп (автокорреляция атак и октавная коррекция), тональность и лад (хрома + профили Крумхансла), энергию, яркость и огибающую громкости. Если песня дана ссылкой, используются жанр, год, темп и характер. |
| `js/system.js` | Визуальная система. Ввод превращается в «паспорт дня»: координаты V/A/W, выбранный приём и акцент, палитра, ритм, поля, зерно, начертания, голос, название папки, а также текстовое объяснение каждого решения. |
| `js/render.js` | Рендер страницы 720×1280. Постоянный каркас и пять приёмов (Моне, Кандинский, Матисс, Ма, Плёнка) плюс акцент второго приёма. |
| `js/demo.js` | Демо-данные: процедурные сцены и синтез музыки через OfflineAudioContext с WAV-кодером. |
| `js/app.js` | Интерфейс: запись дня, архив (IndexedDB), плеер, синхронизированный с песней, озвучка, запись видео .webm, экспорт папки дня в .zip, правка и пересборка. |

## Папка дня (.zip)

`запись.txt`, `фото_N.jpg`, песня (свой файл или `песня_ссылка.txt`), `воспоминание.webm` (если видео записано), `обложка.png`, `озвучка.json` (текст и параметры голоса), `паспорт_дня.json` (все правила и результаты анализа).

## Этика и права

- Чужие песни не скачиваются и не хранятся: для ссылки сохраняется только ссылка. Демо-музыку синтезирует сам прототип.
- Демо-фото нарисованы кодом. Чужие снимки не используются.
- Голос синтезированный, чужие голоса не копируются.
- Оценка настроения — художественная интерпретация, а не диагностика.
- Всё считается локально в браузере, данные никуда не отправляются.

## Инструменты

- Vanilla JS, Canvas 2D, Web Audio API (OfflineAudioContext, AudioContext), MediaRecorder, IndexedDB, Web Speech API.
- JSZip 3.10 (MIT), шрифты Google Fonts (OFL): Cormorant Garamond, Caveat, JetBrains Mono, Unbounded.
- FFT, детектор темпа, определение тональности, k-means, процедурная графика и синтезатор написаны в проекте.
- Генеративные модели внутри продукта не используются: все правила явные и объяснимые.
- Код написан с помощью AI-ассистента Claude (Anthropic) по постановке команды.
